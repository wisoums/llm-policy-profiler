# Security Policy

Do not open a public issue containing real secrets, credentials, PII, confidential prompts, or private customer data.

For suspected vulnerabilities, use GitHub's private vulnerability reporting when available for this repository.

## Security principles

- Privacy-safe telemetry by default.
- No raw prompt/response capture by default.
- No raw PII or secrets in telemetry.
- Low-cardinality metric dimensions.
- Optional integrations must not weaken core security defaults.
- Estimated savings must not be presented as observed provider behavior.
